# 문장풀 문장 추가

`data/fortune.json`에 문장을 추가한다. 이 파일은 `getFortune`이 시드로 **배열 인덱스**를 뽑아 쓰기 때문에, 순서가 바뀌면 이미 공유된 링크의 결과가 달라진다. 아래 규칙은 그걸 막기 위한 것이다.

## 절대 규칙

1. **배열 끝에만 추가한다.** 중간 삽입, 정렬, 순서 변경 금지.
2. **기존 문장 삭제·수정 금지.** 오탈자 수정만 예외이며, 그때도 의미가 바뀌면 안 된다.
3. **구조(키 이름, 등급 키, 중첩)를 바꾸지 않는다.**
4. 추가 전후로 반드시 검증 스크립트와 테스트를 돌린다.

> 문장 수를 늘리면 `getFortune`이 `index % length` 방식일 경우 결과가 바뀔 수 있다. 작업 전에 `lib/fortune/getFortune.ts`의 선택 방식을 확인하고, 기존 결과가 바뀌는 구조라면 작업을 멈추고 사용자에게 알린다.

## 절차

1. **현황 파악**: `node .claude/skills/add-fortune-lines/scripts/check-pool.mjs` 실행. 칸별 문장 수와 20개 미만인 칸, 중복 문장을 확인한다.
2. **대상 정하기**: 사용자가 지정한 칸이 없으면 문장 수가 적은 칸부터 채운다. 칸당 목표는 최소 20개.
3. **문장 작성**: 아래 톤 가이드를 따른다. 기존 문장과 겹치는 표현이 없는지 해당 칸의 기존 문장을 읽고 쓴다.
4. **배열 끝에 추가**: 해당 배열의 마지막 요소 뒤에만 붙인다.
5. **검증**:
  - `node .claude/skills/add-fortune-lines/scripts/check-pool.mjs` — 중복·형식 오류 0건이어야 한다
  - `npm run test` — `getFortune` 스냅샷이 깨지면 안 된다. 깨지면 추가한 내용을 되돌리고 원인을 보고한다
6. **보고**: 칸별 추가 개수와 최종 문장 수를 표로 요약한다.

## 파일 구조

```json
{
  "total": {
    "best":    { "summary": [], "detail": [] },
    "good":    { "summary": [], "detail": [] },
    "normal":  { "summary": [], "detail": [] },
    "caution": { "summary": [], "detail": [] }
  },
  "love":   { "best": [], "good": [], "normal": [], "caution": [] },
  "money":  { "best": [], "good": [], "normal": [], "caution": [] },
  "work":   { "best": [], "good": [], "normal": [], "caution": [] },
  "health": { "best": [], "good": [], "normal": [], "caution": [] },
  "lucky":  { "color": [], "number": [1, 99], "direction": [], "item": [] }
}
```

## 톤 가이드

**공통**
- 부드러운 해요체. 반말·명령조 금지.
- 이모지, 느낌표 남발 금지 (문장당 최대 1개).
- 특정 성별·나이·직업·연애 상태를 가정하지 않는다. ("남자친구", "회사에서" ✕ → "가까운 사람", "하는 일에서" ○)
- 건강·금전 문장은 의학적·투자 조언처럼 들리지 않게 한다. ("병원에 가세요", "주식을 사세요" ✕)
- 날짜·요일·계절에 묶인 표현 금지 (아무 날에나 나올 수 있다).

**길이**
| 칸 | 길이 |
| --- | --- |
| `total.*.summary` | 12–20자, 한 줄 요약. 명사형 종결 가능 ("작은 용기가 큰 행운을 부르는 날") |
| `total.*.detail` | 2–3문장, 60–110자 |
| 분야별 (`love` 등) | 1문장, 15–30자 |

**등급별 톤**
| 등급 | 톤 | 예 |
| --- | --- | --- |
| `best` | 확신, 적극 권유 | 집중력이 최고조, 어려운 일부터 처리해요. |
| `good` | 긍정, 가벼운 권유 | 솔직한 한마디가 마음의 거리를 좁혀요. |
| `normal` | 담담, 작은 팁 | 충동구매만 피하면 무난한 하루예요. |
| `caution` | 조언형. 불안 조장 금지, 대안 제시 | 서두르기보다 한 번 더 확인하면 괜찮아요. |

`caution` 문장은 "나쁜 일이 생긴다"가 아니라 "이렇게 하면 괜찮다"로 끝나야 한다.

**행운 요소**
- `color`: 한글 색 이름만 (예: 실버, 라벤더). 화면에 칩으로 표시되므로 HEX가 필요하면 사용자에게 구조 변경 여부를 먼저 묻는다.
- `item`: 일상에서 흔한 물건, 2–6자 (예: 손목시계, 머그컵). 브랜드명 금지.
- `direction`: 동·서·남·북·남동·남서·북동·북서 중에서만. 이미 다 있으면 추가하지 않는다.
- `number`: 범위 배열이므로 건드리지 않는다.
